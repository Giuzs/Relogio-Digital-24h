# Projeto e Implementação de um Relógio Digital de 24 Horas em Lógica Digital

Este repositório contém o projeto de um Relógio Digital de 24 Horas, cobrindo diferentes etapas de desenvolvimento em Lógica Digital: desde a modelagem e simulação do circuito sequencial no Logisim até a sua aplicação no simulador ”Constructor Virtual y Simulador De Circuitos Digitales” versao 0.9.7.

O objetivo principal é demonstrar a aplicação prática de contadores, lógica de reset, geradores de clock e decodificação para displays de 7 segmentos.
